# File & Folder Structure

## Project Root

```
linkshortenerproject/
├── app/                    # Next.js App Router
├── components/             # Shared React components
│   └── ui/                 # shadcn/ui generated components (CLI only)
├── db/                     # Database layer
│   ├── index.ts            # Drizzle client export
│   └── schema.ts           # Table definitions
├── docs/                   # Agent & developer documentation
├── drizzle/                # Generated migration files (do not edit)
├── lib/                    # Shared utility functions
│   └── utils.ts            # cn() and other helpers
├── public/                 # Static assets
├── proxy.ts                # Clerk middleware (Next.js middleware file)
├── next.config.ts          # Next.js configuration
├── drizzle.config.ts       # Drizzle Kit configuration
├── components.json         # shadcn/ui configuration
└── tsconfig.json           # TypeScript configuration
```

## App Directory

```
app/
├── globals.css             # Global styles + Tailwind v4 theme
├── layout.tsx              # Root layout (ClerkProvider, fonts, header)
├── page.tsx                # Home page route "/"
├── sign-in/
│   └── [[...sign-in]]/
│       └── page.tsx        # Clerk hosted sign-in UI
├── sign-up/
│   └── [[...sign-up]]/
│       └── page.tsx        # Clerk hosted sign-up UI
└── (future routes)
    ├── dashboard/
    │   └── page.tsx        # Authenticated user dashboard
    └── api/
        └── [slug]/
            └── route.ts    # Short-link redirect handler
```

## Naming Conventions

| Item | Convention | Example |
|---|---|---|
| Route files | lowercase | `page.tsx`, `layout.tsx` |
| Component files | PascalCase | `LinkCard.tsx` |
| Utility / hook files | camelCase | `useClipboard.ts` |
| Server action files | camelCase | `actions.ts` |
| DB schema exports | camelCase + `Table` | `linksTable` |

## Where Things Live

| Concern | Location |
|---|---|
| Page UI | `app/**/page.tsx` |
| Shared UI components | `components/` |
| shadcn UI primitives | `components/ui/` |
| Server Functions / Actions | `app/lib/actions.ts` or co-located in the route |
| Data access helpers | `lib/data.ts` (create if needed) |
| DB schema | `db/schema.ts` |
| DB client | `db/index.ts` |
| API routes | `app/api/**/route.ts` |

## Co-location Rules

- Components used **only** by one route can live in a `_components/` subfolder inside that route segment.
- Components used by **multiple** routes belong in the top-level `components/` directory.
- Server Functions used by a single page can be defined inline in the page file using `'use server'` at the function level. If reused, extract to `app/lib/actions.ts`.

## Do Not Modify

These files are auto-generated — do not edit manually:

- `drizzle/**` — Drizzle Kit migration files
- `components/ui/**` — always use `npx shadcn@latest add` instead
- `next-env.d.ts` — auto-generated by Next.js
- `.next/**` — build output
